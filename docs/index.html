Two cores

Mihomo in front, Xray when a node needs it

Mihomo handles the rules, proxy groups, TUN and connection tracking. Nodes that only Xray can run, such as VLESS over XHTTP, go through a local Xray bridge that Kova starts by itself. You don’t set anything up, and you can still pin a profile to one core.

Kova learns which way each site opens

No more adding domains by hand when a site stops loading. Kova notices the failure, tries the site both ways and sends it the way that works: blocked sites through the proxy, sites that refuse the proxy direct.

  1. 1
    Notices

    A site fails on its usual path: a connection error, a reset right after the TLS greeting, or no answer within 6 seconds.

  2. 2
    Checks both ways

    Kova opens the site directly and through the proxy on separate test ports, without touching your traffic.

  3. 3
    Routes it, or asks you

    If no rule chose the path, Kova remembers the site for 30 days. If one of your rules did, it suggests an exception and leaves your rules as they are.

Works with the system proxy and with TUN, where Kova also learns apps that connect by IP address. Turn it on in Rules → Smart routing. Sites that refuse the proxy are sent direct only if you allow it, since that shows them your own address.

    Safe by default

    Leaves your PC the way it found it

    Verified cores

    Mihomo and Xray come from their official GitHub releases. Kova checks each SHA-256 before installing.

    Proxy settings restored

    On disconnect, on quit, and on the next launch after a crash.

    No leftover processes

    Cores run inside a Windows Job Object, so they close together with the app.

    Locked local ports

    The core’s controller and Kova’s own ports need a secret made for your install. On Android so does the proxy port, so other apps can’t use it.

    TUN without running as admin

    A small Windows service only starts and stops Mihomo. The rest of Kova runs as you.

    Signed updates

    Kova checks for updates on launch and installs one only if it is signed with the project’s key.
