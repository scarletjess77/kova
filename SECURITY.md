# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private reporting](https://github.com/scarletjess77/kova/security/advisories/new), not in public issues. Include the Kova version, the system, and the steps to reproduce.

Reports get an answer within a week. Fixes ship in the next release, and the advisory is published once most installs have updated.

## Supported versions

Only the latest release gets security fixes. Kova updates itself, so keeping **Settings → Updates** on is enough.

## Scope

In scope: the Kova app, the Kova service on Windows, the update and core download checks, and the release workflow. Bugs in Mihomo or Xray themselves belong to their own projects ([MetaCubeX/mihomo](https://github.com/MetaCubeX/mihomo), [XTLS/Xray-core](https://github.com/XTLS/Xray-core)).

Never include subscription links, server addresses or keys in a report; replace them with placeholders.
